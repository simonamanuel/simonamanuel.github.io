MailRover

A five-person SFU capstone prototype for indoor parcel distribution, integrating ROS 2 waypoint navigation, a Flask-based task interface, and PIN-authorized electromechanical locker access.

Project Overview

End-to-end parcel dispatch and authenticated retrieval.

Residence staff register a parcel and select a predefined destination. The web application dispatches the task to the navigation stack; at arrival, the locker remains secured until successful recipient PIN validation.

01 Load Register the parcel
02 Dispatch Send the delivery task
03 Navigate Travel to the destination
04 Unlock Check the recipient’s PIN
My Contributions

Web application, access control, and embedded-system integration.

I led the user-interface and access-control workstream, connecting delivery-state management, navigation messaging, PIN authentication, and the locker actuator. I also contributed to team-level wiring, power integration, and functional verification.

01

Web Application

Developed Flask-based staff and recipient workflows for task creation, delivery status, authenticated collection, and PIN entry, including failed-attempt handling.

Flask Interface Delivery Workflow
02

Navigation Interface

Integrated delivery commands and arrival status between the web application and the Raspberry Pi ROS 2 navigation workflow, coordinating cross-subsystem state transitions with teammates.

03

Locker Control

Integrated PIN authentication with the embedded locker-control interface, using GPIO-driven actuation and a solenoid-lock/servo control arrangement.

04

Integration Testing

Validated interactions across Flask services, ROS 2 navigation, embedded I/O, and physical locker hardware; traced timing, communication, and state-transition faults during system integration.

Shared Electrical Integration

Power distribution and electromechanical interfaces.

Assisted with integration of low-voltage battery-powered loads and the wiring between the Raspberry Pi, motor drivers, sensors, and parcel-lock electronics, including regulator and common-ground troubleshooting.

  • Assisted with battery-to-load distribution and DC supply connections across robot subsystems.
  • Checked supply-return routing, common-ground references, and wiring continuity between embedded controllers and actuator circuitry.
  • Investigated supply regulation and power-integrity problems affecting Raspberry Pi operation.
  • Performed subsystem bring-up checks and signal-path troubleshooting during integration.
Web Interface

Task dispatch, mission-state tracking, and secure collection.

The interface exposes parcel intake, mission progress, arrival authorization, and lock-release status to staff and recipients without exposing low-level actuator commands.
